# Portal de casos · propuesta para MeshLab 3D Studio

Maqueta interactiva del portal donde cada ortodoncista sube sus casos (fotos, radiografías, STL y formulario) y los sigue paso a paso hasta la entrega. Tres estilos para elegir.

**Ver:** https://seinp.github.io/meshlab-demo/

- `index.html`: portada con las 3 opciones.
- `portal.html?estilo=clinica | rastreo | arcada`: el portal (doctor y laboratorio).
- Español e inglés (`?lang=en`).

Datos de ejemplo. Ningún archivo sale del equipo de quien la prueba.

Diseño y desarrollo: [SEINP](https://seinp.github.io/).
